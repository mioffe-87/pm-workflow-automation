LLBLGen Pro v4.0 Readme
=========================================================
You've just installed LLBLGen Pro, the powerful O/R mapper - code generator for .NET. 

If you installed LLBLGen Pro Lite
===================================
LLBLGen Pro Lite is fully functional and not time limited, however the entity model is
limited to 8 entities. Furthermore, Lite comes without any support. You are allowed to
use the generated code in production.

If you requested a trial license
===================================
The trial license you received via e-mail should be placed in the directory in which you've
installed LLBLGen pro. The application will be time-limited: it is fully functional for 
30 days, starting at the day you requested the demo license. After that it refuses to 
work and you have to uninstall LLBLGen Pro. If you want to continue working with 
LLBLGen Pro after the time trial period, you have to purchase per seat licenses at 
http://www.llblgen.com.

If you purchased a per seat license
===================================
When you purchased a license, you received your license file(s) via e-mail. 
One license file, LLBLGenPro4_x.License (where x is a number), is a per seat license,
usable on a single install on a single computer, and should be placed in the directory 
in which you've installed LLBLGen Pro. 

If you purchased a site license
===================================
When you purchased a site license, you received your license file via e-mail. 
The license file,  LLBLGenPro4_x.License, is usable by any individual within your 
department/division, and should be placed in the directory in which you've installed LLBLGen Pro.
