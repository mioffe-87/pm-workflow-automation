Create a project  
  


Click the New Project... button on the toolbar.
In the small dialog which pops up, fill in the project name, the name of the creator, the location and which target framework to use.
Click 'Create'.
Your project is created in the Project Explorer at the left side of the LLBLGen Pro Designer.
The Project Settings dialog pops up. Have a look at the project settings or accept the default settings.
