Refresh relational model data  
  


Make a change to the database schema in your RDBMS, e.g. remove a field of a table which is mapped by an entity in your project.
Right-click the Relational Model Data Storage node (expand the 'Relational Model Data' node) in Project Explorer or Catalog Explorer and select Refresh Relational Model Data from a Database from the context menu.
The Relational Model Data Retrieval Wizard is started. Complete the wizard's steps to obtain the relational model data from your database.
LLBLGen Pro will now migrate your Abstract Entity Model and will show the log of the actions performed afterwards. If you for example removed a field in the database, or renamed a field in the database, it will show you that it for example has left a field unmapped as there's no target field found, or has mapped the entity field on a different field now (the renamed field).
